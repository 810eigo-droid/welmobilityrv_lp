# CamPit 広告配信用LP（LP1）

トヨタ・ハイエースベースのキャンピングカー「CamPit」の機能訴求型ランディングページです。
SNS・Web広告の着地ページとして、**出口をLINE登録の一点に絞った**構成になっています。

## 特徴

- **単体HTMLファイル1つで完結**（CSS・JS内蔵）。サーバーにフォルダごとアップするだけで公開できます
- **グローバルナビなし**（ヘッダーはロゴ＋LINEボタンのみ）＝離脱経路を作らないLP設計
- **スマホ完全対応**。画面下にLINEボタンが常時固定表示されます
- **モード切替タブ**（ドライブ／ダイネット／フルフラット）で、同じ車内が3つに変化する様子を体験的に見せます
- **FAQはアコーディオン**（開閉式）で縦に長くなりません
- 画像が未設置の間は、**ファイル名と推奨サイズを表示した仮画像**が自動で表示されます

## 公開方法

`lp1` フォルダをそのままサーバーにアップロードしてください。

例：`public_html/lp1/` に置いた場合 → `https://welmobilityrv.com/lp1/` で公開されます
（フォルダ名は自由に変更できます。広告のリンク先にこのURLを設定してください）

### 撮影・作成時のポイント

- **`mode_drive` / `mode_dinette` / `mode_flat` の3枚は、同じアングル・同じ明るさで撮影してください。**
  タブを切り替えたときに「同じ場所が変化した」と伝わることが、このLPの一番の見どころです。
- **`bed_open` と `bed_cargo` の2枚も同じアングル**で撮ると、着脱のビフォーアフターが際立ちます。
- サイズは目安です。多少違っても自動でトリミング表示されます（すべて横長推奨）。
- 1枚あたり500KB以下に圧縮すると、広告からの表示速度が上がります（広告費の効率に直結します）。
- `fv_campit.webp` と `cta_bg.webp` は上に文字が乗ります。**中央〜右側に被写体、左側に余白**のある構図だと文字が読みやすくなります。

## ✏️ 設定済み・未設定の項目

- **LINEのURL**：設定済み（`https://s.lmes.jp/landing-qr/...`／全5箇所）
- **フッター**：電話対応を行っていないため、電話番号・営業時間は記載していません。問い合わせ導線はLINEに一本化しています
- **プライバシーポリシー**：現在リンクなし（下記メモ参照）

## ページ構成

1. ファーストビュー（キャッチコピー＋3つのFEATUREバッジ＋LINE導線）
2. 共感・課題提起（4つのお悩み）
3. **機能訴求（メイン核）** — 機能01：モード切替タブ／機能02：着脱ビフォーアフター／機能03：マルチテーブル
4. ラインナップ 3モデル（価格非表示）
5. ご購入までの簡単5ステップ
6. よくあるご質問（アコーディオン・全6問）
7. LINE限定 3大コンテンツ
8. ボトムCTA
9. ベース車両・信頼性情報
- 固定LINEボタン（PC：右下／スマホ：画面下部バー）

## メモ：プライバシーポリシーについて

Google広告・Meta広告では、リンク先ページにプライバシーポリシーの掲載を求められる場合があります（LINE登録を通じて個人情報を取得するため）。審査で指摘された場合は、公式サイト側にページを用意し、フッターにリンクを追加すれば対応できます（雛形はリポジトリの `v2/legal/` フォルダにあります）。
