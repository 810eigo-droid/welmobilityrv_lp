# WordPress（SWELL）組み込み用ブロック一式

`index.html` をSWELLのカスタムHTMLブロック用にセクション分割したものです。
全CSSは `.wmrv-lp` クラスの内側だけに効くように隔離してあるため、SWELL本体のデザインとは干渉しません（SWELL側のCSSからの影響も `& *` リセットでほぼ遮断されます）。

## 組み込み手順

### 1. 画像のアップロード
`images/` フォルダの全画像をWordPressの「メディア」にアップロードします。
アップロード後、**各ブロック内の `images/〜` をメディアのURLに置き換え**てください。
（例：`images/fv_main.png` → `https://ドメイン/wp-content/uploads/2026/08/fv_main.png`）
※FTPが使える場合は、サイト直下に `images/` フォルダごと置けば置換不要です（固定ページがルート表示の場合のみ）。

### 2. 共通CSSの登録
「外観 → カスタマイズ → 追加CSS」に `00_共通CSS.css` の中身を丸ごと貼り付けます。

### 3. 固定ページの作成
1. 新規固定ページを作成
2. SWELLのページ設定：レイアウト「1カラム（フルワイド）」、ページタイトル非表示、コンテンツ上下の余白なし
3. カスタムHTMLブロックを追加し、`02`〜`10` と `12` の中身を番号順に貼り付け
4. 最後にカスタムHTMLブロックで `99_アニメーション用スクリプト.html` を貼り付け
5. 「設定 → 表示設定」でこの固定ページをホームページに指定

### 4. ヘッダー・フッターについて（01・11は任意）
- **SWELLのヘッダー/フッターを使う場合**：`01`・`11` は貼り付け不要です。
- **LPのヘッダー/フッターを使う場合**：`01`・`11` も貼り付け ＋ SWELL側のヘッダー/フッターをカスタマイザーで非表示にしてください。`01` のヘッダーは画面上部固定（position:fixed）です。

## 納品前に差し替える箇所
- LINEのURL：`https://lin.ee/xxxxxxx`（02・09・10・12内）→ 公式LINEのURLへ
- フッターの住所・電話番号（11内）
- SNSリンク（11内）

## 見出しフォントの変更
丸ゴシック（Zen Maru Gothic）がデフォルトです。ゴシックに変える場合は、追加CSS内の
`--font-round:'Zen Maru Gothic','Noto Sans JP',sans-serif;`
を
`--font-round:'Noto Sans JP',sans-serif;`
に書き換えるだけで全見出しに反映されます。

## 技術メモ
- 共通CSSはCSSネスト記法（2023年以降の主要ブラウザ対応）を使用しています。
- `.fv` と `.final` の `isolation:isolate` は背景画像（負のz-index）の表示に必須です。削除しないでください。
- ブロックの表示アニメーション（スクロールでふわっと表示）は `99` のスクリプトが担当します。貼り忘れると全セクションが非表示のままになるので注意（`reveal` クラスが `opacity:0` のため）。
