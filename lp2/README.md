# ウェルモビリティRV 広告配信用LP（LP2）｜月々4万円台強調型

キャンピングカー定額リース「ウェルモビリティRV」の**価格訴求型（月々4万円台〜）**ランディングページです。
SNS・Web広告の着地ページとして、**出口をLINE登録の一点に絞った**構成になっています。

## 特徴

- **単体HTMLファイル1つで完結**（CSS・JS内蔵）。サーバーにフォルダごとアップするだけで公開できます
- **グローバルナビなし**（ヘッダーはロゴ＋LINEボタンのみ）＝離脱経路を作らないLP設計
- **スマホ完全対応**。画面下にLINEボタンが常時固定表示されます
- デザインは**緑（アウトドア感）×ネイビー（信頼感）**を基調とし、**金色のアクセント**で「月々4万円台〜」の価格帯を強調しています
- **FAQはアコーディオン**（開閉式）で縦に長くなりません
- 画像が未設置の間は、**ファイル名と推奨サイズを表示した仮画像**が自動で表示されます

## 公開方法

`lp2` フォルダをそのままサーバーにアップロードしてください。

例：`public_html/lp2/` に置いた場合 → `https://welmobilityrv.com/lp2/` で公開されます
（フォルダ名は自由に変更できます。広告のリンク先にこのURLを設定してください）

### 撮影・作成時のポイント

- **`fv_city` と `fv_camp` はFVで左右に並べて表示されます。**明るさ・トーンを揃えると一枚絵のように美しく見えます（スマホでは上下に並びます）
- **`bed_open` と `bed_cargo` の2枚は同じアングル**で撮ると、着脱のビフォーアフターが際立ちます
- サイズは目安です。多少違っても自動でトリミング表示されます
- 1枚あたり500KB以下に圧縮すると、広告からの表示速度が上がります（広告費の効率に直結します）
- `final_bg.webp` は上に文字が乗ります。**中央に文字用の余白**がある構図だと読みやすくなります

## ✏️ 設定済み・未設定の項目

- **LINEのURL**：設定済み（`https://s.lmes.jp/landing-qr/...`／LP1と同じURL・全6箇所）
- **フッター**：電話対応を行っていないため、電話番号・営業時間は記載していません。問い合わせ導線はLINEに一本化しています
- **プライバシーポリシー**：現在リンクなし（LP1のREADMEのメモ参照。雛形はリポジトリの `v2/legal/` フォルダにあります）
